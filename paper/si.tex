Correct rates are grouped by the type of the first annotator's answer; Answer F1 by type is the
official evaluator's grouping, by the type of the reference that gave the best F1. Yes/no and
unanswerable references get almost no F1 from a full-sentence answer, which is why F1 is not used
as the main measure. Oracle has fewer unanswerable questions because it is asked only where an
annotator marked evidence.
